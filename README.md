# SAI2 XInput2 / WinTab pen-pressure patch for Wine

A source patch for **64-bit PaintTool SAI 2** on Linux. It routes XInput2 tablet motion/pressure data into Wine's WinTab path so SAI2 can receive pressure when a tablet's Linux driver exposes the pen through XInput2.

This project does **not** include PaintTool SAI2, SAI2 license files, tablet drivers, or any proprietary SAI assets. Download SAI2 yourself from SYSTEMAX.

- Official SAI2 Development Room: <https://www.systemax.jp/en/sai/devdept.html>
- Wine 11.20 source: <https://dl.winehq.org/wine/source/11.x/wine-11.20.tar.xz>

## Choose an installation method

### A. Prebuilt Wine (no compiling)

The release archive generated by this project is for **CachyOS/Arch-family x86_64**. If a matching archive is attached to the GitHub Release, download and extract it under your home directory, then follow docs/INSTALLATION.md.

**Do not use that CachyOS-built binary on every Linux distribution.** It links to the build host's system libraries. On Ubuntu, Fedora, Debian, openSUSE, other architectures, or older system libraries, build locally from source instead.

### B. Build a patched Wine on your own Linux system

Install Wine's build dependencies for your distribution, including the MinGW-w64 cross compiler and X11/XInput2 development files. Examples are in docs/BUILD-DEPENDENCIES.md. The build script checks required tools and refuses to continue if XInput2 was not detected. Then run:

    ./scripts/build-from-source.sh

The script downloads the official Wine 11.20 source, applies the clean patch without fuzz, checks that XInput2 headers were detected, builds an x86_64 Wine, installs it under ~/.local/opt/wine-sai2-11.20-xinput2, and performs a small Windows-command smoke test.

If your system has limited RAM, limit parallel jobs:

    JOBS=4 ./scripts/build-from-source.sh

Building Wine is resource-intensive. The patch itself is small; compiling Wine is the optional source-build path, not an end-user requirement when a compatible prebuilt package is available.

## User workflow

1. Download the **64-bit** SAI2 ZIP from the official SYSTEMAX site and extract it into a folder you control. Keep that folder intact.
2. Either install a compatible prebuilt Wine release asset, or build Wine from source using the script above.
3. Create a launcher and optionally a Desktop shortcut and/or applications-menu entry:

    ./scripts/install-sai2.sh --wine "$HOME/.local/opt/wine-sai2-11.20-xinput2/bin/wine" --sai2 "/absolute/path/to/your/SAI2-folder/sai2.exe" --shortcut both

Choose --shortcut desktop, --shortcut menu, or --shortcut none instead of both as needed. Paths with spaces are supported when properly quoted. The installer creates a separate win64 Wine prefix for this patched SAI2 setup and does not alter the user's system Wine or SAI2 files.

## Repository contents

- patches/wine-11.20-xinput2-pen-pressure.patch — clean unified patch against official Wine 11.20 source.
- scripts/build-from-source.sh — build and install Wine from source.
- scripts/install-prebuilt-wine.sh — install a matching optional prebuilt release archive.
- scripts/install-sai2.sh — configure SAI2 and optionally create desktop/menu launchers.
- scripts/launch-sai2.sh — quiet default launcher with size-limited logs.
- scripts/package-prebuilt-runtime.sh — build a stripped runtime archive on the current host for a GitHub Release.
- scripts/collect-diagnostics.sh — make a local diagnostic report for troubleshooting.
- tests/validate-patch.sh — verify the patch applies to pristine Wine 11.20 without fuzz.
- docs/COMPATIBILITY.md — supported scope and test status.

## Debug logging

The distributed patch contains **no SAI_DIAG instrumentation** and no high-volume diagnostic logging added during development. The launcher uses WINEDEBUG=-all by default and rotates log files. For a one-off diagnostic launch:

    SAI2_DEBUG=1 "$HOME/.local/bin/sai2-wine-xinput2"

Debug mode can generate larger logs; it is off by default. Do not publish diagnostic logs without reviewing them for local paths and other personal information.

## Validation status

The patch was generated against pristine Wine 11.20 files and checked with patch --dry-run --fuzz=0. A clean x86_64 build and installation succeeded on the maintainer's CachyOS rolling host; the built driver was checked for the patch symbols and for absence of SAI_DIAG, and Wine successfully ran cmd /c ver in a fresh 64-bit prefix.

That is **not** a claim that all tablets, Linux distributions, GPU stacks, or SAI2 versions work. The final real-world check still needs a user to open SAI2 with their tablet and confirm both pen movement and pressure response. See docs/COMPATIBILITY.md.

The prebuilt install path was also tested from an isolated, initially empty HOME on the maintainer's CachyOS/glibc 2.44 host. It installed the runtime, created a fresh win64 prefix, passed cmd /c ver, and created Desktop/menu shortcuts without launching SAI2. Contributors can repeat this packaging check with tests/smoke-clean-install.sh /absolute/path/to/official-64-bit-sai2.exe [runtime-archive.tar.xz]. This does not replace the physical-tablet test.
